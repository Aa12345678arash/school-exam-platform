# سامانه آزمون آنلاین و هوشمند مدرسه

**شناسه پروژه:** SCHOOL-EXAM-001  
**مخزن:** https://github.com/Aa12345678arash/school-exam-platform  
**وضعیت:** مرحله صفر — تثبیت مشخصات و آماده‌سازی پیاده‌سازی

## هدف
ساخت یک سامانه آنلاین ارزشیابی و یادگیری برای مدارس ابتدایی؛ شروع با کلاس ۵۰۲ دبستان شهید منوچهر شریفی در کرمانشاه و توسعه‌پذیر برای پایه‌های اول تا ششم و چندین مدرسه.

## نسخه آزمایشی نخست
- کلاس: پنجم ۵۰۲
- ظرفیت اولیه: ۳۱ دانش‌آموز
- نخستین آزمون: مطالعات اجتماعی، درس‌های ۱ تا ۶
- مدت: ۴۵ دقیقه
- تعداد سؤال: ۴۰
- بارم کل: ۲۰ نمره

## اصول غیرقابل مذاکره
1. متن سؤال‌ها، گزینه‌ها و بارم مصوب آموزگار بدون اجازه تغییر نمی‌کند.
2. کلید پاسخ حدس زده یا در رابط دانش‌آموز افشا نمی‌شود.
3. تصحیح تشریحی هوش مصنوعی صرفاً پیشنهاد است و تأیید نهایی با آموزگار است.
4. اطلاعات دانش‌آموزان محرمانه و دسترسی مبتنی بر نقش است.
5. پرونده تحصیلی در طول سال‌ها حفظ می‌شود.
6. هیچ نسخه‌ای پیش از آزمون عملی و تأیید آموزگار برای دانش‌آموزان منتشر نمی‌شود.

## وضعیت فعلی
مخزن اختصاصی ایجاد شده و مستندات پایه در حال ثبت است. هنوز برنامه اجرایی، پایگاه داده، احراز هویت، حساب دانش‌آموزی یا لینک آزمون منتشر نشده است. متن دقیق همه ۴۰ سؤال و کلید پاسخ در دسترس فعلی مخزن نیست؛ بنابراین آزمون به‌صورت داده ساختگی وارد نشده است.
