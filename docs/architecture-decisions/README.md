# Architecture Decision Records (ADR)

تصمیم‌های مهم فنی در این پوشه ثبت می‌شوند.

## ADR-0001 — انتخاب فناوری اصلی
**وضعیت:** پیشنهادی / تصمیم نهایی نشده

### زمینه
پروژه به وب‌اپ واکنش‌گرا، احراز هویت امن، پایگاه داده رابطه‌ای، ذخیره فایل خصوصی، نقش‌ها و استقرار قابل اتکا نیاز دارد.

### گزینه اولیه
- Lovable برای کمک به ساخت رابط و برنامه
- Supabase برای PostgreSQL، احراز هویت، ذخیره فایل و Row Level Security
- GitHub برای کنترل نسخه و بازبینی تغییرات

### ملاحظات
- مالکیت و قابلیت خروجی گرفتن از کد
- هزینه و محدودیت‌های سرویس
- امنیت داده دانش‌آموزان و کنترل دسترسی
- امکان تست خودکار و محیط staging
- پشتیبان‌گیری و بازیابی
- قابلیت توسعه چندمدرسه‌ای

### تصمیم
هنوز انتخاب قطعی انجام نشده است. پیش از پیاده‌سازی احراز هویت و داده واقعی، معماری و هزینه‌ها باید بررسی و تصمیم در همین ADR ثبت شود.
